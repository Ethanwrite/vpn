# 星火 VPN · 扁平线性标志

以 `emblem.json` 的 200 × 200 轮廓为源，`emblem.svg` 为可直接使用的透明矢量稿。暖白 #F6F4EF、炭灰 #282825、暗红 #922D28；成功状态绿 #287853。

锤柄为完整闭合轮廓，镰刀具有收尖的刀刃和独立握柄。交叉处通过遮罩隐藏镰刀被锤柄遮住的部分，不截断锤柄。SVG 中黑色只用于不可见的 mask，不是背景。Android 动态图用差集裁剪，VectorDrawable 用 evenOdd 裁剪。自适应桌面图标由系统提供暖白底；传统 PNG/ICO 均保留透明背景。

未连接：小幅分离、完整轮廓。连接中：650 ms 平移扣合、轻微透明度变化。已连接：静止标志、绿色小点、中文状态。系统关闭动画时停用动效。没有圆盘、放射线、光晕或发光阴影。

## 实现

- Android：XingsuiEmblemView、ic_xingsui_emblem、launcher 前景及各密度 PNG。
- Windows：EmblemGraphic 共用 BrandMark/ConnectButton，ICO 包含 16–256 px 图层。
- 官网：导航静态标志、首页交互标志使用同组路径；动画明确标注为演示。
- Android 首页为固定布局，并提供横屏双栏布局；会员/到期信息保留在个人页，首页按钮为 60 dp / 16 dp 圆角。

## 指标口径

Android 上传/下载为隧道累计字节增量除以单调时钟时间差（5 秒刷新）；首个样本、断开和计数重置时显示 —。延迟每 15 秒测量一次，使用显式绑定 VPN 网络的 TCP 连接至 1.1.1.1:443，超时 2.5 秒。无法取得 VPN 网络或测量失败时显示 —。

Windows 上传/下载继续使用内核实时流量；延迟为经当前本地代理请求连通性检查地址的实际响应耗时，每 15 秒一次，超时 3 秒。它包含代理、TLS 和服务响应时间，与 Android 的 TCP 建连耗时不可直接横向比较。测量只用于展示，不改变连接授权或断线策略。
